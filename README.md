# Aangan — AI lead-response and site-visit booking assistant

Django REST + React. Buyers chat in English, Hindi or Gujarati, get answers only from the sales head's fact sheet,
and book real free site-visit slots. Serious buyers go to a named executive with a summary.
See `deployment.md` to run it and `TDD.md` for the design.

```
backend/   Django project (config/) and app (core/: models, services/, views, tests/, seed command)
frontend/  React + Vite (pages/, components/, styles.css)
```
